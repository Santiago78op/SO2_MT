2. Enunciado de la Práctica

Esta práctica tiene como propósito que los estudiantes preparen un entorno de desarrollo
funcional en Linux para la compilación de software a bajo nivel. Se busca que comprendan
la relación entre las herramientas de compilación, las librerías de desarrollo y el kernel del
sistema operativo.

2.1 Descripción del problema a resolver

El entorno de desarrollo del laboratorio requiere la instalación y configuración de un
conjunto de herramientas de compilación para poder analizar, modificar y recompilar
componentes del kernel Linux. Sin estas herramientas, no es posible realizar prácticas de
desarrollo o depuración del sistema operativo.

El estudiante deberá instalar y verificar el funcionamiento de GCC, make, GDB y las
librerías de desarrollo de C en gnu/linux, asegurando que pueda compilar correctamente el
kernel sin realizar modificaciones mayores.

2.2 Alcance de la práctica


Obligatorio:

     Instalar GCC, make, GDB y las librerías de desarrollo de C.
     Descargar el código fuente del kernel Linux y ejecutar el proceso de configuración y

         compilación sin errores críticos.
     Deshabilitar la verificación de firmas para los módulos.
     Modificar el EXTRAVERSION del makefile para mostrar su nombre y número de

         carné.
     Compilar el kernel.
     Documentar el procedimiento y los resultados de las pruebas.

Opcional:

     Automatizar parte del proceso de verificación con un script bash.
     Realizar comparativas de tiempos de compilación entre diferentes configuraciones

         del sistema.

2.3 Requerimientos técnicos

La práctica se desarrollará en un entorno gnu/linux usando una distribución basada en
Debian (Se recomienda Linux Mint).

Se deberán utilizar las siguientes herramientas:

     GCC: compilador de C.
     make: gestor de construcción de proyectos.
     GDB: depurador para programas en C.
     Paquetes de desarrollo: librerías y encabezados necesarios para compilar el

         kernel.

El estudiante deberá comprobar las versiones instaladas, ejecutar pruebas básicas de
compilación y realizar la configuración inicial del kernel mediante los comandos make
localmodconfig, make -jX, make modules_install y make install.

3. Entregables
