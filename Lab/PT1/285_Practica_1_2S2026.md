3. Enunciado de la Práctica
Esta práctica tiene como objetivo que los estudiantes comprendan la estructura interna del
kernel de Linux y su proceso de compilación mediante la modificación de una llamada al
sistema real. En este caso, se añadirá un contador que registre cuántas veces se ha
invocado la función sys_getpid(), demostrando cómo los cambios en el código del kernel
pueden alterar su comportamiento, y se implementará una llamada al sistema que imprima
este contador llamada getpid_counter().
3.1 Descripción del problema a resolver
En el desarrollo de software moderno, el sistema operativo actúa como una "caja negra"
para la mayoría de los programadores. Sin embargo es fundamental comprender que cada
acción realizada en el espacio de usuario (como obtener el ID de un proceso) depende de
una ejecución privilegiada en el Kernel.
El reto planteado consiste en la instrumentación del núcleo de Linux. Actualmente, la
llamada al sistema sys_getpid() simplemente devuelve el PID del proceso actual sin dejar

3.2 Alcance de la práctica
La práctica se considera completada con éxito cuando se cumplen lo siguiente:
1. Obtención y Preparación: Descarga y extracción del código fuente de una versión
estable del Kernel de Linux (versión indicada en el lab).
2. Modificación del Código: Localización exacta del archivo fuente donde reside
sys_getpid() y la declaración de una variable global para el conteo. A su vez la
creación de una nueva llamada de sistema para visualizar este contador en dmesg.
3. Gestión de Logs: Implementación de la función printk para imprimir en el log del
kernel el valor actual del contador.
4. Compilación e Instalación: Generación del binario del nuevo kernel , instalación de
los módulos necesarios y actualización del gestor de arranque (GRUB).
5. Verificación: Ejecución de un programa en C en espacio de usuario que invoque
sys_getpid() repetidas veces y la posterior comprobación de que el contador
incrementa correctamente en los registros del sistema llamando a getpid_counter().

● Sistema Operativo: Distribución Linux (basado en Debian).
